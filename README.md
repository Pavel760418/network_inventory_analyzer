# Анализ инвентаризации собственного производства

Модуль считает недостачи, излишки, пересорты, перекрытия и отдельно показывает хозтовары, тару и упаковку.
Подзаголовок рабочего экрана: контроль недостач, излишков, пересортов, перекрытий и причин инвентаризационных отклонений по магазинам сети.

Публичное приложение: ссылка появится после одного деплоя владельцем аккаунта, см. [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

## Возможности

- Операционный рейтинг без хозтоваров, тары и упаковки. Их суммы остаются в финансовом итоге.
- Пары пересорта только из редактируемого справочника. Кандидат не уменьшает недостачу.
- Резерв категорий с формулой и детализацией. Это не экономия.
- Отдельный контур говядины.
- Полные списки в Excel. Top-10 только на дашборде.
- Синтетический пример без реальных данных.

## Локальный запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Проверки: `pytest tests -q`.

## Входной файл

Исходная выгрузка инвентаризации, лист с иерархией подразделения и документами `Инвентаризация <номер> от дд.мм.гггг`.
Готовый файл анализа программа отклоняет.
Второй файл, по желанию: оприходование излишков при закрытии смены.

## Справочники

См. [docs/CONFIGURATION_GUIDE.md](docs/CONFIGURATION_GUIDE.md).

- `config/related_product_pairs.csv`
- `config/item_scope_classification.csv`
- `config/scope_rules.csv`
- `config/beef_scope.csv`

Пример пары «Семга стейк» ↔ «Форель стейк» требует подтверждения и сам недостачу не закрывает.

## Как читать резерв

Резерв = max(min(недостача категории, излишки категории) − уже применённое перекрытие, 0).
Подробности: [docs/METHODOLOGY.md](docs/METHODOLOGY.md).

## Как читать рейтинг

Выше балл — лучше. Хозтовары в балл не входят. Веса v4: 0.35, 0.25, 0.25, 0.15.
На экране магазина есть блок «Почему этот магазин на этом месте?».

## Оприходованные излишки

Группа A связана с недостачей, группа B — кандидат, группа C — связи нет.
Для группы C причина помечена как гипотеза и требует проверки.

## Полный Excel

Кнопка «Скачать полный Excel» на вкладке «Полные списки и экспорт».
Лист «Полнота_выгрузки_и_контроль» сверяет число строк.
