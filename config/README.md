# Справочники

Все правила, которых нет в выгрузке, задаются здесь и могут быть изменены без правки кода.

| Файл | Назначение |
|------|------------|
| `related_product_pairs.csv` | Допустимые пары пересорта |
| `item_scope_classification.csv` | Точечная классификация SKU. Важнее правил |
| `scope_rules.csv` | Правила по уровню иерархии и фрагменту имени |
| `beef_scope.csv` | Подтверждённый контур говядины |

Пара уменьшает недостачу только если тип связи — прямая замена и заполнено поле `approved_by`.
Тип `requires_manual_review` остаётся кандидатом.

Пример «Семга стейк» ↔ «Форель стейк» записан как кандидат и требует подтверждения.
Он не является утверждённой взаимозаменяемостью.

Позиция без строки классификации получает статус «Не классифицировано» и не исключается из рейтинга.
