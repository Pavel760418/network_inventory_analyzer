# Политика публичных данных

В публичный репозиторий входят код, документация, шаблоны справочников и синтетический пример.

Не публикуются:

- реальные выгрузки инвентаризации и финансовые отчёты;
- локальный эталон `data/master_hierarchy.json` с фактической номенклатурой;
- `.env`, `.streamlit/secrets.toml`, токены;
- каталоги `output/`, `exports/`, `reports/`, `uploads/`, `temp/`.

Пользователь загружает свою выгрузку в сессию. Приложение не пишет её в репозиторий и не печатает содержимое в журнал.
Синтетические имена магазинов: «Магазин Альфа», «Магазин Бета».
