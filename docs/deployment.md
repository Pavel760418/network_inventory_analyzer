# Деплой

## Локально

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

В боковой панели включите «Синтетический пример» или загрузите свою исходную выгрузку.
Файл пользователя пишется во временный каталог сессии и удаляется после расчёта.
Абсолютные пути Windows приложению не нужны.

## Публичный Streamlit

Репозиторий подготовлен для Streamlit Community Cloud.
Одно ручное действие владельца аккаунта:

В Streamlit Community Cloud открыть New app → выбрать репозиторий, ветку main и app.py → нажать Deploy.

Пароль и токен в этот репозиторий не кладутся.
Пока это действие не выполнено, публичный URL не существует.
Приложение не требует логина GitHub у конечного пользователя после публикации.

Секреты Streamlit не нужны. Файл `.streamlit/secrets.toml` создавать не следует.
