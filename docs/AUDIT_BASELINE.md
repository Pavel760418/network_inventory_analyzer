# Аудит текущего модуля (baseline до расширения v2)

Аудит выполнен по коду до добавления контура собственного производства.
Расчётные формулы v4 не переписывались.

## Структура

Точки входа: `main.py` (CLI), `app_legacy.py` (прежний Streamlit), `app.py` (дашборд v2).
Язык: Python 3.10+. Зависимости: pandas, numpy, openpyxl, streamlit, python-dotenv, pytest.

Поток v4:

1. `src/parser.py` читает выгрузку TDSheet.
2. `src/catalog.py` ставит категорию из `data/master_hierarchy.json`, если файл есть локально.
3. `src/overlap.py` считает однородное перекрытие внутри магазина.
4. `src/metrics.py` считает рейтинг.
5. `src/anomalies.py`, `src/price_compare.py`, `src/capitalization.py` — аномалии сумм, цены, оприходование.
6. `src/excel/export.py` собирает прежний отчёт.

## Вход

Обязательные маркеры шапки: «документ.подразделение», «количество книжное», «количество фактическое», «сумма излишек», «сумма недостача».
Документ распознаётся строкой `Инвентаризация <номер> от дд.мм.гггг`.
Колонки читаются по позиции: 1 учётное количество, 2 фактическое, 3 разница количества, 4 учётная сумма, 5 фактическая сумма, 6 разница суммы, 7 сумма излишка, 8 сумма недостачи.

## Формулы, которые нельзя менять без согласования

- Недостача количества = модуль отрицательной разницы количества. Недостача суммы = модуль колонки «сумма недостача», с запасным правилом из разницы суммы.
- Излишек количества = положительная разница. Излишек суммы = положительная колонка «сумма излишек».
- Перекрытие v4: внутри одной `category_group` и одного магазина, количество не расходуется дважды, сумма перекрытия = min(остаток суммы излишка, количество × цена недостачи).
- Рейтинг v4: shrinkage 0.35 + восстановление 0.25 + чистые недостачи 0.25 + число SKU с расхождениями 0.15. Выше балл — лучше. Класс A выше 80, B выше 50, иначе C.
- «РЦ» и «Фабрика-кухня» не входят в розничный признак `is_retail`, но их строки в v4 остаются в суммах.
- Кандидат справочника пар не уменьшает недостачу.

## Листы прежнего Excel

Содержание, Сводка, Рейтинг магазинов, Оприходование излишков, Аномалии, Проверка цен, Мероприятия, Перекрытие, Выводы, Анализ позиций, Вне справочника, Документы, Метаданные, листы магазинов.

## Обрезки v4, которые v2 больше не использует в полном отчёте

- Перекрытие на листе: `head(500)`.
- Документы: `head(500)`. Позиции: `head(500)`. Вне справочника: `head(2000)`.
- Топы сети: `TOP_N_NETWORK = 50`. Топы магазина: `TOP_N_STORE = 10`.
- Пул пар при объёме больше 2 500 000: `head(1200)` на сторону. Это ограничение самого алгоритма v4, не только листа. В v2 оно сохранено, потому что снятие лимита меняет результат на больших файлах и требует отдельного согласования.

## Что изменено в v2

Добавлены справочники контура, пар, говядины, полный Excel без Top-N на детальных листах, рейтинг только по операционному контуру, резерв категорий как отдельная величина, дашборд Streamlit.
Формулы недостачи, излишка и однородного перекрытия v4 не заменялись.

## Что не подтверждено

Модуль v4 считает всю выгрузку сети. Ветка «Производство Зеленого яблока» есть в локальном эталоне, но отдельного фильтра в v4 не было. В v2 операционный рейтинг исключает хозтовары, тару и упаковку по справочнику. Неклассифицированные строки не исключаются.
